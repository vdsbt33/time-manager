# Time Manager
Uma ferramenta open-source de produtividade para ajudar você a gerenciar seu tempo.

## Primeiros passos
Antes de iniciar, você precisar ter as seguintes ferramentas instaladas:

- IDE ou editor de texto de sua escolha, ex: Visual Studio Code
- Node v20.x (https://nodejs.org/en/download/prebuilt-installer)

## Como iniciar
- API
    - Dentro de api/, execute `npm run start`
- Web
    - Dentro de web/, execute `npm run start`
